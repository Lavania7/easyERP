# release1.1 使用说明

## 工作表顺序

1. **产品源数据表**：维护 `PID`、`登记名称`、`现有库存`。
2. **物料源数据表**：维护 `MID`、`物料名称`、`供应商料号`、`类型`、`现有库存`。
3. **BOM总表**：录入 PID，并粘贴外部 BOM 数据。产品名称和 MID 自动匹配。
4. **物料需求**：按 BOM 数量和生产计划计算毛需求、建议采购量和预计余量。
5. **计划总览**：填写计划立即生产和计划预备生产数量。

## 新增产品并计算物料需求

以下以新增 `P005` 为例。

### 1. 登记产品

打开“产品源数据表”，在 P004 下一空行填写：

- PID：`P005`
- 登记名称：产品名称
- 现有库存：当前成品库存

请连续使用空白行，不要在已有数据中间插入空行。

### 2. 粘贴外部 BOM

在外部 BOM 文件中，从第二列 `Quantity` 开始，向右选择到最后一列 `收费原因`，复制需要的全部数据行。

在“BOM总表”中找到下一空行：

1. 在该行 A 列填写 `P005`，并向下填充到本次 BOM 的所有行。
2. 从该行的 D 列“数量”开始粘贴外部 BOM 数据。

不要覆盖 B 列“产品名称”、C 列“MID”、AO 列“匹配状态”和 AP 列“计划生产数量（计算）”，这些列由公式维护。

### 3. 处理未匹配物料

“BOM总表”的 MID 根据外部 BOM 的 `Comment` 与“物料源数据表”的“物料名称”做精确匹配。

- 匹配成功：MID 显示物料编号，匹配状态为“已匹配”。
- 匹配失败：MID 显示红色“不匹配”，匹配状态为“待登记物料”。

处理“不匹配”时，在“物料源数据表”的下一空行登记 MID 和物料信息。**物料名称必须与 BOM 的 Comment 完全一致**，包括空格、大小写、符号和单位写法。登记后，BOM 中相同 Comment 的行会自动匹配。

物料名称应保持唯一。如果同一个物料名称对应多个 MID，系统会按“不匹配”处理，避免选错料号。

### 4. 填写生产计划

打开“计划总览”，找到 P005。只填写黄色的两列：

- 计划立即生产
- 计划预备生产

“计划生产合计”和“计划后成品库存”会自动计算。

### 5. 确认物料需求

打开“物料需求”查看结果：

- 毛需求 = 各 BOM 行的数量 × 对应 PID 的计划生产合计，再按 MID 汇总。
- 建议采购量 = `MAX(0, 毛需求 - 现有库存)`。
- 预计余量 = `现有库存 - 毛需求`。
- 状态显示“需采购”或“库存充足”。

此表不再显示 P001 到 P004 的单件用量列，也不显示单独的“计划合计”区。

## 使用注意事项

- 当前模板预留 100 个产品、200 个物料和 500 行 BOM。超出范围时需要扩展公式区域。
- 只在黄色单元格中维护源数据、PID、外部 BOM 内容和生产计划。
- 删除或移动公式列会中断联动。
- “BOM待处理行”不为 0 时，应先处理缺少 PID、产品不匹配或物料未登记，再确认采购结果。
- 初始 BOM 中仍有部分 Comment 未在物料源数据表登记，因此会显示“不匹配”；按上述步骤登记后即可参与需求计算。

## 已验证的 P005 流程

已分别在生成引擎和桌面版 Excel 中模拟以下流程：新增 P005、登记新物料、粘贴 BOM、填写两类生产计划，并检查物料需求。产品名称、MID、计划合计、毛需求和建议采购量均能联动更新；未登记物料会保持红色“不匹配”，不会被误计入已登记 MID 的需求。
